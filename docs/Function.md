# 食蛙 Unieat — 初版功能
## 1.首页
- 模块布局：顶部搜索栏，简单轮播图（校园餐饮活动、热门菜品、优惠信息），下方四个入口卡片：
- 签到：每日签到获取积分，连续签到有额外奖励。
- 活动：展示当前食堂活动（如新品尝鲜、节日特惠）。
- 订餐：跳转至“订餐”页面。
- 积分：显示用户当前积分余额，可查看兑换规则。

- 随机美食推荐
    - 每次进入首页，随机显示菜品卡片（包含菜名、缩略图、所属食堂/档口、价格）。
    - 点击卡片可进入菜品详情页，显示更多信息与图片。

## 2.食堂信息
- 食堂列表：
    - 显示校园内所有食堂的基本信息（位置、营业时间、档口数量）。
    - 支持搜索，和首页一样跳转搜索页面；
    - 档口与菜品信息
    - 每个食堂下展示档口列表（档口名、主营菜系、当前营业状态）。
    - 菜品信息包括：菜名、价格、学生上传的图片、标签（如“麻辣”“素食”）。

- 菜品图片来源：
    - 学生可在菜品详情页上传自己拍的菜品照片（需简单审核自动过滤低质量图）。
    - 每上传1张有效图片，奖励固定积分（如10分）。
    - 重复上传同一菜品将不获得积分。


## 3.积分系统
- 获取方式：签到、上传菜品照片、参与活动等；
- 使用方式：可在“积分”页面查看规则，并兑换餐劵（后期可扩展成食堂优惠券、饮品券）。
- 积分明细：记录每次获取/消耗的时间与来源

## 4.订餐（暂不做）
- 选择食堂 → 档口 → 菜品 → 加入购物车 → 确认
- 提示当前菜品预计等待时间（可后期结合人流量检测）

## 5. 用户消费统计
- 消费记录：按日/周/月统计用户消费金额（模拟数据或基于订餐记录生成）。
- 消费习惯分析（MVP 可先做简单饼图/柱状图）：如最常点的菜、最常去的食堂。
- 积分记录：与消费记录同页面展示，方便对比

## 6.用户页面
- 基本信息：昵称、头像、学号（可选）、当前积分。
- 我的上传：展示用户上传的菜品照片。
- 统计入口：跳转到消费统计页面。
- 积分兑换记录：查看已兑换的餐劵/优惠券。

### 相关逻辑整理：
- 登录：在 home 页面已经完成微信登录 + openid → token 的主链路。 所以在 user 页面里不需要再做登录。
  - 授权头像 & 昵称：
    - 第一次进入 user 页面，如果数据库里没有用户的头像和昵称 → 显示 默认头像和默认昵称。 
    - 弹出 vant-weapp Dialog 提示“是否使用微信头像和昵称”。 
    - 用户拒绝 → 保持默认头像/昵称。 
    - 用户同意 → 通过 wx.getUserProfile 获取微信头像和昵称 → 上传到后端，存入数据库，前端刷新。
- 头像修改逻辑：
    - 头像区域可点击。 
    - 如果当前是默认头像 → 点击时可授权获取微信头像和昵称。 
    - 如果已经使用过微信头像 → 可以 重新授权更新（例如换了微信头像）。 
    - ⚠️ 一旦换成微信头像和昵称 → 不可以再改回默认。
- 退出登录：
    - 在页面底部提供一个按钮 → 点击后清空本地 token → 跳转到 home 页 → 弹出登录框。 
    - 保证 未登录用户无法使用小程序（已经在 home 里限制了）。
- 后端头像处理：
    - 前端传给后端的 avatar_url 是微信头像的临时 URL（有效期短）。 
    - 后端要： 
      - 下载该头像文件 
      - 存入 Django 的 MEDIA_ROOT/user_avatars/ 
      - 数据库里只保存本地路径（如 /media/user_avatars/xxx.jpg） 
      - 更新头像时，删除旧头像，存储新头像。

# 欢迎页
| 模块       | 前端展示 & 交互需求                    | 后端数据接口 & 存储需求            |
|----------|--------------------------------|--------------------------|
| **欢迎背景** | 页面顶部或全屏显示欢迎图片；自适应屏幕宽高；支持后端动态替换 | 提供获取 Welcome 图片接口；存储图片文件 |
| **欢迎文字** | 显示欢迎语（可固定，也可后台可配置）             | 提供欢迎语字段；可存数据库中           |
| **跳转按钮** | 点击进入首页或其他功能页面                  | 无需接口，前端本地路由              |
